# 호랑 PM파트 사전 과제

업데이트 일정 역산 자동화 시스템 설계 과제입니다.

## 저장소 구조

```text
.
├── data/
│   └── source/      # 과제에서 제공된 원본 데이터
├── docs/            # 문서 산출물
├── sql/             # DB 생성 및 조회 SQL
├── scripts/         # 데이터 적재 및 계산 스크립트
├── dashboard/       # 일정 역산 상황판
├── output/          # 실행 결과
└── README.md
```

## 원본 데이터

과제에서 제공된 원본 파일은 `data/source/`에 보관합니다.

원본 파일은 직접 수정하지 않고, 분석 및 가공 과정에서 생성되는 데이터는 별도 파일로 관리합니다.

현재 원본 데이터는 다음과 같습니다.

- `과제문서_호랑PM파트.html`
- `jira_issues.csv`
- `jira_worklog.csv`
- `md_baseline_v0.csv`
- `calendar.csv`
- `people.csv`
- `jira_api_raw_sample.json`
- `dashboard_mockup.html`

## 실행 방법

구현이 진행되는 동안 아래 항목을 순차적으로 작성합니다.

1. 실행 환경 준비
2. 데이터 적재
3. DB 생성
4. MD 계산
5. 핵심 조회 쿼리 실행
6. 대시보드 실행

현재는 저장소 및 원본 데이터 구성을 완료한 상태이며, 구현이 진행됨에 따라 실제 실행 명령어를 이 문서에 추가합니다.
